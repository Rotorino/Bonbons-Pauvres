# API Bonbons Pauvres

Express-сервер обслуживает статический сайт из `frontend/public/` и JSON API по префиксу `/api`.

## Каталог

| Метод и путь | Назначение |
|---|---|
| `GET /api/categories` | Список категорий конфет. |
| `GET /api/dishes` | Каталог конфет. Поддерживает необязательный параметр `category_id`. |
| `GET /api/services` | Преимущества компании для страницы «О компании». |
| `GET /api/articles` | Статьи: заголовок, анонс, текст и дата публикации. |

## Заявки

`POST /api/contact` принимает JSON или URL-encoded данные:

```json
{
  "name": "Анна",
  "phone": "+7 (999) 123-45-67",
  "email": "anna@example.com",
  "message": "Хочу заказать дегустацию",
  "consent": "on"
}
```

Сервер валидирует поля, сохраняет заявку в PostgreSQL и асинхронно отправляет уведомление в Discord, если в `.env` указан `DISCORD_WEBHOOK_URL`. Успешный ответ — `200`, ошибка валидации — `400` с полем `error`.

## Голосование

| Метод и путь | Назначение |
|---|---|
| `GET /api/poll` | Активный опрос, варианты и признак голосования в текущей сессии. |
| `GET /api/poll/results` | Результаты активного опроса: голоса и проценты. |
| `POST /api/vote` | Голосование. Тело: `{ "optionId": 1 }`. Повторный голос в той же сессии возвращает `409`. |

## Служебный endpoint

`GET /health` возвращает статус приложения.

## Конфигурация

Все секреты находятся только в `.env`. Для Discord можно указать `DISCORD_SOCKS5_PROXY`: тогда только webhook-запросы проходят через SOCKS5-прокси.
